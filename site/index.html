快速安装

三步完成部署

1

下载最新 发布包 并解压

2

将 Ultra ULX 文件夹放入 garrysmod/addons/

3

重启服务器，控制台显示 Ultra ULX v2.98.51 启动完成 即成功

安装后需在服务器控制台执行 ulx adduserid <你的SteamID> superadmin 获取管理员权限。

常见问题

遇到问题先看看这里

Unknown command: ulx？
检查目录是否多了一层嵌套：addons/Ultra ULX/lua/ 必须直接存在。
怎么给自己管理员权限？
服务器控制台执行 ulx adduserid <你的SteamID> superadmin。SteamID 可用聊天框 !who 查看。
命令无反应？
确认自己有对应权限（SuperAdmin / Admin）。
语言切换后乱码？
输入 ulx_lang zh-cn 切回中文。
怎么卸载？
删除 addons/Ultra ULX/ 文件夹（可选删除 data/ultra_ulx/），重启服务器即恢复原版 ULX。
想反馈 Bug 或建议？
到 GitHub Issues 提交，有 Bug / 功能建议模板可用。
