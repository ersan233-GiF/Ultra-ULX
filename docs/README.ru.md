## О проекте

[Ultra ULX](https://github.com/ersan233-GiF/Ultra-ULX) — расширенный форк плагина администрирования Garry's Mod [ULX](https://github.com/TeamUlysses/ulx). Помимо всех оригинальных функций добавляет:

- **150+ команд администрирования** (в оригинале ~45)
- **Полную локализацию** — **4 языка** (упрощённый китайский / English / Русский / классический китайский), переключается каждым клиентом
- **SQLite-персистентность** системы наказаний (автоматические резервные копии + восстановление)
- **Авто-бхоп (BHOP)**, HUD координат, спавн предметов и 23 функциональных модуля
- **Конструкция без вмешательства**: все данные хранятся в отдельном каталоге `data/ultra_ulx/` — оригинальный ULX не изменяется, а его удаление мгновенно восстанавливает ванильный ULX

> **Совместимость:** построен на ULX v3.81 + ULib v2.72, поставляется с полным ULib — дополнительная установка не требуется.

## Установка


```
1. Скачайте релиз — на верхнем уровне zip находится папка "Ultra ULX". Распакуйте её прямо в garrysmod/addons/
2. Перезапустите сервер
3. Успех подтверждается сообщением в консоли "Ultra ULX v2.98.52 loaded"
```

> **Проверка каталога:** итоговый путь должен быть `garrysmod/addons/Ultra ULX/lua/...` (без лишней вложенной папки).

### Использование прямо из этого репозитория

```
git clone https://github.com/ersan233-GiF/Ultra-ULX.git
# Скопируйте папку "Ultra ULX" целиком в garrysmod/addons/
```

## Использование команд


| Способ | Пример | Описание |
|:----|:-----|:-----|
| Чат `!команда` | `!bring игрок` | Самый частый способ, ввод в игре |
| Консоль `ulx_команда` | `ulx bring игрок` | Для админов |
| `!menu` или `!xgui` | Открыть панель | Полная админ-панель XGUI |

Краткий справочник команд:

```
ulx map <карта>                  ← сменить карту
ulx ban <игрок> <минут> <причина>   ← забанить игрока
ulx kick <игрок>                 ← кикнуть игрока
ulx gag <игрок> <минут>          ← таймер-гаг (голос)
ulx mute <игрок> <минут>         ← таймер-мут (чат)
ulx warn <игрок> <причина>       ← предупредить (3→авто-гаг, 5→авто-бан)
ulx noclip                       ← ноклип себе
ulx god                          ← режим бога себе
ulx hp 100                       ← восстановить здоровье
ulx cleanup                      ← очистить все пропы на карте
ulx bring <игрок>                ← притянуть игрока к себе
ulx goto <игрок>                 ← телепортироваться к игроку
ulx freeze <игрок>               ← заморозить игрока
ulx ragdoll <игрок>              ← превратить игрока в регдолл
```

## Первоначальная настройка сервера


### Шаг 1: Получите свой SteamID

SteamID — ваш уникальный идентификатор (например `STEAM_0:1:12345678`), который не меняется даже при смене ника. Назначать админов по SteamID надёжнее всего.

```
Способ 1: введите !who в чате
         → ваш SteamID появится в выводе (например "STEAM_0:1:55554444")

Способ 2: откройте https://steamid.io/ в браузере
         → введите URL вашего профиля Steam

Способ 3: Steam → Друзья → ПКМ по себе → Просмотреть профиль
         → число в конце URL — ваш Steam64 ID (нужна конвертация; способ 1 проще)
```

> Запишите свой SteamID (формат `STEAM_0:1:12345678`) — понадобится дальше.

### Шаг 2: Назначьте себя SuperAdmin

После установки при первом входе у вас нет прав. Используйте **консоль сервера** (не игровой чат):

```
# Консоль сервера (rcon/бэкенд):
ulx adduserid <вашSteamID> superadmin

# Например, если ваш SteamID STEAM_0:1:55554444:
ulx adduserid STEAM_0:1:55554444 superadmin
```

> **Совет:** играете локально (Одиночная → Новая игра → Песочница)? Нажмите `~` для консоли.
> **Совет:** арендованный сервер? Используйте консоль/RCON в панели хостинга.
> **Почему SteamID?** Ники можно менять в любой момент; SteamID привязан навсегда — права сохраняются при смене ника.

Затем введите `!menu` в чате, чтобы открыть полную админ-панель.

### Шаг 3: Проверка прав

```
Команды в чате:
!who               ← увидеть свою группу (и свой SteamID)
!version           ← информация о версии Ultra ULX
```

Если видите `You do not have access to this command` — предыдущий шаг не сработал. Повторите `ulx adduserid` и проверьте формат SteamID.

### Шаг 4: Частые команды сервера

```
# Консоль сервера:
ulx map gm_construct           ← переключиться на карту
ulx ban ИмяИгрока 60 причина   ← бан на 60 минут
ulx kick ИмяИгрока             ← кикнуть игрока
ulx noclip                     ← ноклип себе
ulx god                        ← режим бога
ulx hp 100                     ← восстановить здоровье
ulx cleanup                    ← очистить все пропы
```

### Управление группами

> **Рекомендуется: через SteamID** — права сохраняются при смене ника.

```
# По SteamID (рекомендуется, постоянно):
ulx adduserid STEAM_0:1:55554444 superadmin    ← SuperAdmin (макс.)
ulx adduserid STEAM_0:1:55554444 admin         ← Admin
ulx adduserid STEAM_0:1:55554444 operator      ← Operator
ulx removeuserid STEAM_0:1:55554444            ← удалить пользователя

# Или по имени игрока (временно, сброс после смены ника):
ulx adduser ИмяИгрока superadmin               ← добавить по имени
ulx removeuser ИмяИгрока                       ← удалить по имени
```

> Совет: `!who` показывает имена и SteamID всех онлайн-игроков.

### Админ-панель XGUI

```
Введите !menu (или !xgui) в чате:
├── Команды     ← просмотр/выполнение всех команд ulx
├── Группы      ← визуальное управление пользователями и группами
├── Баны        ← просмотр/разбан
├── Предметы    ← спавн оружия/предметов/транспорта
├── Голосование ← настройка голосования за карту
└── Настройки   ← MOTD сервера / язык / скин
```

## Сосуществование с оригинальным ULX

| Сценарий | Поведение |
|:----|:-----|
| Оригинальный ULX уже установлен | Ultra ULX автоматически переопределяет одноимённые команды |
| Установлен только Ultra ULX | Поставляется с полным ULib, доп. установка не нужна |
| Удалить Ultra ULX | Оригинальный ULX полностью сохраняется |

## Удаление


```
1. Удалите всю папку addons/Ultra ULX/
2. (Необязательно) удалите конфигурацию data/ultra_ulx/
3. Перезапустите сервер — оригинальный ULX восстанавливается автоматически, без остатков
```

> **Конструкция без вмешательства:** все данные в отдельном каталоге `data/ultra_ulx/`; оригинальный ULX никогда не изменяется.

## FAQ


| Проблема | Решение |
|:----|:-----|
| `Unknown command: ulx` | Проверьте лишнюю вложенность: `addons/Ultra ULX/lua/` должен существовать напрямую |
| `Groups file was not formatted correctly` | Удалите `data/ulib/groups.txt` и перезапустите — пересоздастся автоматически |
| Команды не работают | Убедитесь, что у вас есть права (SuperAdmin/Admin) |
| Кракозябры после смены языка | Введите `ulx_lang zh-cn` для возврата к китайскому |
| Как дать себе права? | Консоль сервера: `ulx adduserid <вашSteamID> superadmin` |
| Забыл свой SteamID? | Введите `!who` в чате |
| BHOP не работает? | Проверьте другие физические плагины; некоторые режимы (напр. DarkRP) имеют свои ограничения движения |
| Предметы не спавнятся? | Проверьте лимиты в `data/ultra_ulx/sbox_limits.txt`, или категории в `!menu` → Предметы |

## Безопасность


- Все пути записи санируются и экранируются (`sql.SQLStr`) — защита от SQL-инъекций
- Команда `ulx url` имеет встроенный белый список доменов — защита от открытых редиректов
- Клиентский RPC использует белый список пространств имён (`ulx.*` / `ULib.*`)
